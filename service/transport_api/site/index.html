Transport

Swiss public transport API

Introduction

The Transport API allows interested developers to build their own applications using public timetable data, whether they're on the web, the desktop or mobile devices. The aim of this unofficial API is to cover public transport within Switzerland. It answers from the national timetable and its real-time data, published as open data on opentransportdata.swiss - see where the data comes from and how the API came about.

If you are looking for an officially supported source or need to download all data e.g in GTFS format, please check opentransportdata.swiss.

The source code of the Transport API can be found on GitLab, please ask any technical questions there. If you need a direct contact write an email to transport@opendata.ch.
