Transport

Swiss public transport API

MCP server for AI assistants

This address is not a web page: it is a Model Context Protocol server. Add it to your AI assistant, and it can look up stations, connections and departures of Swiss public transport for you, with platforms and real-time delays. No key and no login.

https://transport.opendata.ch/mcp

Adding it

  • Claude (claude.ai, desktop): Settings › Connectors › Add custom connector, name «Transport», URL above.
  • ChatGPT (web; Business, Enterprise, Edu and Pro): Plugins › + › Add custom MCP server, URL above; the server needs no authentication. In a chat, type @ and pick it.
  • Claude Code: 
    claude mcp add --transport http transport https://transport.opendata.ch/mcp
  • VS Code, Cursor and other clients, in mcp.json: 
    {
  "servers": {
    "transport": { "type": "http", "url": "https://transport.opendata.ch/mcp" }
  }
}

Then ask, for example: «Next departure from Bern, Engeried?» or «How do I get from Zürich HB to Bern by 9 tomorrow?»

Tools

  • find_stations: stations and stops by name, with their ids.
  • stations_nearby: the stops closest to a coordinate.
  • connections: connections from A to B, with platforms, delays and changes.
  • departures: the departure or arrival board of a station.

All tools only read, from the national timetable of opentransportdata.swiss. More in the documentation; what happens to a request: privacy.
